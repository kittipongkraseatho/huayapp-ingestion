# กลุ่มสูตร VIP ตามภาพอ้างอิง — Design Spec

## เป้าหมาย

ปรับการแสดงผลสูตร VIP ให้เหลือ 3 หมวดที่อ่านง่ายบนมือถือและเรียงเหมือนภาพอ้างอิง โดยคง logic การคำนวณ ตัวเลขที่คำนวณ และปุ่มคัดลอกเดิมทั้งหมด

## การจัดกลุ่ม

| หมวด | สูตรเดิม | ชื่อที่แสดง |
| --- | --- | --- |
| สูตรรูด 19 ประตู | ID 2, 3 | สูตร 1, สูตร 2 |
| สูตรพิกัด | ID 5, 6 | พิกัดบน, พิกัดล่าง |
| สูตรปัก | ID 9, 13, 15, 18 | ปักสิบบน, ปักสิบล่าง, ปักหน่วยบน, ปักหน่วยล่าง |

## UI

- ลบ filter เดิมที่แบ่งเป็น `ทั้งหมด`, `หน่วย`, `หลัก`, `สูตร`
- แสดงหัวข้อหมวด 3 หัวข้อเหนือการ์ด
- แสดงการ์ดเรียงแนวตั้งตามลำดับในภาพ เพื่อให้มือถืออ่านต่อเนื่อง
- การ์ดยังคงแสดงลูกบอลตัวเลข, ชุดเลขย่อย, ปุ่มคัดลอก และ click-to-copy เดิม
- ใช้สี/กรอบ/เงาเดิมของหน้าเว็บ ไม่เปลี่ยนธีมเป็นสีแดง/ทองทั้งระบบ
- ชื่อหมวดและชื่อการ์ดต้องใช้ข้อความภาษาไทยตามตาราง

## พฤติกรรม

- หลังคำนวณ แสดงทั้ง 8 สูตรใน 3 หมวดพร้อมกัน
- filter เดิมไม่เหลือใน DOM และไม่ต้องมี state filter ใหม่
- ปุ่ม `คัดลอกสูตรสำเร็จรูป`, บันทึกผล, ประวัติ และสูตรหุ้นยังทำงานกับข้อมูลเดิม
- ฟังก์ชัน `computeBalls`, `buildPillSets`, `copyVipFormulaFromCard` และสูตรใน `VIP_FORMULAS` ไม่เปลี่ยนวิธีคำนวณ

## การทดสอบยอมรับงาน

- หลังคำนวณเห็นหัวข้อ 3 หมวดตามลำดับ
- หมวดแรกมี ID 2, 3; หมวดสองมี ID 5, 6; หมวดสามมี ID 9, 13, 15, 18
- ชื่อการ์ดตรงกับตาราง
- จำนวนการ์ดรวมยังเป็น 8
- ลูกบอลและชุดเลขของ input เดิมยังเหมือนก่อนปรับ UI
- ปุ่มคัดลอกของการ์ดยังทำงาน
- หน้า mobile เรียงการ์ดเป็นหนึ่งคอลัมน์ตามภาพ
